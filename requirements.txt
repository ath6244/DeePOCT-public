# DeepOCT-Ultra — runtime dependencies (everything EXCEPT torch / torchvision).
#
# ============================================================================
# INSTALL torch FIRST, separately, with the CUDA build that matches your GPU,
# THEN run `pip install -r requirements.txt`.
#
# WHY: pytorch_wavelets and focal-frequency-loss both declare `torch` as a
# dependency. If torch is NOT already installed, pip will pull a default torch
# wheel (possibly CPU-only or the wrong CUDA build) as a transitive dependency.
# Installing the correct CUDA torch FIRST means pip sees the requirement already
# satisfied and leaves your wheel untouched.
#
#   Step A — read the GPU + driver CUDA version (no torch needed):
#       nvidia-smi                  # note the GPU model and "CUDA Version"
#
#   Step B — install the matching torch CUDA wheel (example: CUDA 12.1):
#       pip install torch --index-url https://download.pytorch.org/whl/cu121
#       # choose cu118 / cu121 / cu124 ... to match your driver; see pytorch.org.
#       # torchvision is NOT used by this repo — install it ONLY if you add code
#       # that needs it:
#       #   pip install torchvision --index-url https://download.pytorch.org/whl/cu121
#
#   Step C — confirm the GPU is usable for THIS torch build:
#       python gpu_check.py         # expect: cuda True, and your sm_XX in arch list
#
#   Step D — install the rest (this file). torch is already satisfied -> untouched:
#       pip install -r requirements.txt
# ============================================================================
#
# Versions are pinned to the locally-validated set (Python 3.14, torch 2.12).
# If the torch CUDA wheel you pick forces a different numpy ABI, relax the numpy
# pin (e.g. `numpy>=2.0`) and reinstall.
